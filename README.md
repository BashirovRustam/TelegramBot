# 📌 Модели и поля (на русском)

## Пользователь (User)
**Поля:**
- `id` — PK  
- `telegram_id` — уникальный Telegram ID  
- `полное_имя`  
- `роль` — Enum: **КЛИЕНТ | МАСТЕР | АДМИН**  
- `активен`  
- `создано_в`  

**Связи:**
- `записи_созданные` → `Запись.created_by`  
- `записи_назначенные` → `Запись.master_id`  

---

## Салон (Salon)
**Поля:**
- `id` — PK  
- `название`  
- `адрес`  
- `описание`  
- `активен`  

**Связи:**
- `услуги` → `Услуга.salon_id`  
- `мастера` → `Мастер.salon_id`  
- `записи` → `Запись.salon_id`  

---

## Услуга (Service)
**Поля:**
- `id` — PK  
- `salon_id` → `Салон.id`  
- `название`  
- `длительность_минут`  
- `цена`  
- `активна`  

**Связи:**
- `мастера` через `МастерУслуга` (many-to-many)  
- `записи` → `Запись.service_id`  

---

## Мастер (Master)
**Поля:**
- `id` — PK  
- `user_id` → `User.id`  
- `salon_id` → `Салон.id`  
- `активен`  

**Связи:**
- `услуги` через `МастерУслуга` (many-to-many)  
- `записи` → `Запись.master_id`  
- `расписание` → `РасписаниеМастера.master_id`  

---

## МастерУслуга (MasterService)
**Поля:**
- `master_id` → `Мастер.id`  
- `service_id` → `Услуга.id`  

---

## РасписаниеМастера (MasterSchedule)
**Поля:**
- `id` — PK  
- `master_id` → `Мастер.id`  
- `день_недели` — 0–6  
- `время_от`  
- `время_до`  

---

## Запись (Appointment)
**Поля:**
- `id` — PK  
- `клиент_id` → `User.id` (роль КЛИЕНТ)  
- `salon_id` → `Салон.id`  
- `master_id` → `Мастер.id`  
- `service_id` → `Услуга.id`  
- `дата`  
- `время_начала`  
- `время_конца`  
- `статус` — Enum: **ЗАБРОНИРОВАНО | ОТМЕНЕНО | ЗАВЕРШЕНО**  
- `создано_в`  

**Связи:**
- `клиент` → `User`  
- `мастер` → `Master`  
- `салон` → `Salon`  
- `услуга` → `Service`  

---

## Вложение записи (TaskAttachment)  
**Поля (опционально, для файлов/подтверждений):**
- `id`  
- `appointment_id` → `Запись.id`  
- `telegram_file_id`  
- `загружено_в`
