## 📌 О проекте

**Beauty Salon Bot** — это асинхронный Telegram-бот для автоматизации записи клиентов в салон красоты. Проект реализован как **pet-project**, но с ориентацией на **production-архитектуру**, приближенную к реальным коммерческим системам.

### 🧩 Архитектурный подход

Проект построен с использованием современных подходов к разработке Telegram-ботов:

* 🤖 **Асинхронный бот на aiogram 3.x** — отвечает за:
  * диалоговое взаимодействие с пользователями
  * управление состояниями через FSM (Finite State Machine)
  * обработку команд и callback-запросов
  * валидацию пользовательского ввода

* 🔗 **Интеграция с внешними API**:
  * 🗺️ **2GIS API** — поиск адреса салона, отображение карты, построение маршрутов

* 🗄️ **Постоянное хранилище данных**:
  * PostgreSQL для хранения данных о записях, клиентах и услугах
  * Redis для FSM-состояний и кеширования

### 🔌 Взаимодействие компонентов

* Полностью асинхронная архитектура (async/await)
* FSM для управления многошаговыми диалогами
* Фоновые задачи через Celery для уведомлений о предстоязей записи
* Корректное завершение работы и обработка ошибок (logging и запись логов с уровнем WARNING, ERROR)

### 🔹 Ключевые возможности

* 🔹 Запись на услуги салона через интерактивный диалог
* 🔹 Выбор мастера, услуги и времени
* 🔹 Просмотр и отмена существующих записей
* 🔹 Интеграция с 2GIS для отображения местоположения салона

Проект демонстрирует уверенное владение **aiogram**, **async Python**, **FSM-паттернами**, **интеграцией внешних API** и **чистой backend-архитектурой**.

## 🔄 FSM (Finite State Machine)

Бот использует FSM для управления сложными многошаговыми диалогами.

### 📋 Пример: процесс записи

```
┌─────────────────┐
│  /book command  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ SELECT_SERVICE  │ ← Выбор услуги
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ SELECT_MASTER   │ ← Выбор мастера
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  SELECT_DATE    │ ← Выбор даты
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  SELECT_TIME    │ ← Выбор времени
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ CONFIRM_BOOKING │ ← Подтверждение
└────────┬────────┘
         │
         ▼
         │
         ▼
┌─────────────────┐
│     SUCCESS     │ ← Запись создана
└─────────────────┘
```

На каждом этапе:
- ✅ Валидация ввода
- ↩️ Возможность вернуться назад
- ❌ Возможность отменить операцию
- 💾 Сохранение промежуточных данных в Redis
